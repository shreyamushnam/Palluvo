# PALLUVO — “Every drape, a little magic”

A luxury saree and drape fashion brand website built from scratch with an ultra-premium editorial magazine aesthetic inspired by contemporary Indian haute couture and international fashion publications.

---

## Brand Essence & Design Ethos

- **Brand**: PALLUVO
- **Tagline**: *“Every drape, a little magic”*
- **Aesthetic**: Restrained luxury, editorial asymmetry, generous whitespace, tactile paper feel, and fluid textile movement without generic e-commerce layouts.
- **Color Palette**:
  - Warm Ivory (`#FAF7F2`) & Soft Cream (`#F5EFEB`)
  - Deep Charcoal (`#1C1A18`)
  - Muted Wine / Burgundy (`#541920`)
  - Soft Terracotta (`#BF6A54`)
  - Subtle Antique Gold (`#C5A575`)
- **Typography**: *Cormorant Garamond* editorial serif display headers paired with clean *Montserrat* sans-serif body text.

---

## Features & Sections

1. **Minimal Luxury Navigation**: Frosted glass sticky header on scroll, bag and wishlist counters, search drawer trigger, and collector circle account preview.
2. **Editorial Hero Composition**: Asymmetric typography, calibrated 3:4 high-fashion photography in full color, craftsmanship indicators, and magnetic CTAs.
3. **The PALLUVO Mood (Section 2)**: Magazine spread split-screen layout with an interactive *Our Story* modal.
4. **Signature Collections (Section 3)**: Dramatic asymmetric layout showcasing *The Silk Edit*, *Midnight Drapes*, *Festive Stories*, and *Everyday Poetry*.
5. **Shop The Drape (Section 4)**: Product discovery with real-time category filtering, dual-angle hover swap, wishlist toggle, and quick view.
6. **Drape Stories (Section 5)**: Interactive storytelling guide covering *The Classic*, *The Contemporary*, *The Effortless*, and *The Statement*, complete with step-by-step blueprints and stylist notes.
7. **Fabric Close-Up (Section 6)**: Immersive macro visual with interactive glowing weave hotspots (*Antique Gold Zari*, *Mulberry Weft*, *Resham Tassels*).
8. **The PALLUVO Journal (Section 7)**: Magazine essays with an interactive full-screen story reader modal.
9. **Seen in the wild (Section 8)**: Masonry social editorial gallery with photo lightbox.
10. **Brand Statement (Section 9)**: Monumental minimal typography statement: *“Not just a saree. A feeling you carry.”*
11. **Newsletter (Section 10)**: *“Stay in the fold.”* with instant confirmation and zero-spam commitment.
12. **Multi-Column Luxury Footer**: Multi-currency selector (INR ₹, USD $, EUR €, GBP £), concierge assistance, and links.

### Interactive Global Capabilities
- **Shopping Bag Slide-Over**: Item quantity updates, removal, complimentary heirloom packaging toggle, subtotal calculation, and checkout simulation.
- **Wishlist Slide-Over**: Persistent saved items with one-click *Move to Bag*.
- **Search Modal**: Instant search across fabrics, weaves, colors, and origins with curated tag chips.
- **Quick View Modal**: Dual-angle photo switcher, Silk Mark certification, weave specs, and direct add-to-bag.

---

## Technical Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 & Vanilla CSS custom design tokens
- **Icons**: Lucide React & custom luxury brand icons
- **State Management**: React Context with LocalStorage persistence

---

## Getting Started

### Prerequisites
- Node.js 18.18+ or 20+

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the site.

### Production Build
```bash
npm run build
npm run start
```
